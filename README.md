# 柴犬斗地主 (Shiba DouDiZhu)

三人斗地主网页游戏，玩家与两个电脑玩家对战，支持三种 AI 难度。

## 技术栈

- **前端框架**: React 18 + TypeScript
- **样式方案**: Tailwind CSS
- **动画库**: Framer Motion
- **构建工具**: Vite

## 开始使用

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 类型检查
npm run typecheck
```

## 游戏规则

### 发牌
- 54 张牌（包含大小王）
- 每人 17 张牌，留 3 张底牌

### 叫地主
- 系统从随机玩家开始
- 玩家可选择"抢"或"不抢"
- 最先"抢"的玩家成为地主，获得底牌（共 20 张）

### 出牌
- 必须出比上家大的牌型，或选择"不出"
- 地主先出完牌则地主胜，农民任意一人先出完则农民胜

### 牌型大小
大王 > 小王 > 2 > A > K > Q > J > 10... > 3

## AI 难度

| 难度 | 说明 |
|------|------|
| 简单 | 随机出牌，适合新手 |
| 普通 | 基础策略，优先出短顺子 |
| 困难 | 深度策略，会记牌和配合 |
